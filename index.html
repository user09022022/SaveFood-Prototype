Quick start

Course demonstration route

1. Manager: set up a restaurant, add food and set the quantity.
2. Customer: find the restaurant, order an item, and choose Pickup or Delivery.
3. Manager: Accept → Ready → create a reminder → Picked Up / Delivered.
4. Customer: verify history and reminder. Separately test Pending cancellation and manager rejection; stock should be restored.

Use one browser for both roles. The demo accounts below are browser-only, not Android database credentials. Confirm actual Android behavior on an emulator before presenting.

New account workflow

Register as a manager, then set up a restaurant on the dashboard. Add food, switch to a customer, and search the same city. Profile changes, listings, orders, reminders and sessions survive refresh. Reset restores the starting demo.

Demo scope

Sample accounts and food are preloaded for this web demo. The demo manager owns Green Garden. Other sample restaurants are for browsing. Your teammates each have their own browser data; use one browser to demonstrate both roles. No email or push message is sent. Guest browsing, password recovery and dietary filtering remain unavailable, matching the inspected app.

Browser storage simulates the Android Room / SQLite persistence. It does not connect to your Android installation. The screen layouts are source-based recreations, not emulator screenshots.
